# AI生成17世纪海盗帆船Blender动画
Author: @Ayu_AI_0912
Original post: https://x.com/Ayu_AI_0912/status/2109043294911291886
Prompt & live remake: https://workskill.tools/ai-videos/opus-5-5/ayu-ai-0912-mv3dh62y

▼プロンプト▼
架空の海賊船（17世紀のガレオン船風・3本マスト・船名なし）について、
CAD図面と Blender 動画を作ってください。

【図面】2D の DXF のみ（3Dモデルの書き出しは不要）。単位 mm、A2 の図枠と表題欄つき。
1. 甲板平面図 S=1:100（船の中心線を y=0 にした実際の位置で描く）
2. 側面図（帆装図）S=1:150
3. 正面図・船尾図・中央横断面図 S=1:150
特記事項に「架空の船のイメージで、実在の船の図面ではない」と書く。
寸法は Python の形状モジュール1つで決め、図面と動画の両方がそれを読み込む。

【動画】Blender（EEVEE）、1920×1080・24fps・本編20秒＋ロゴ3.5秒、音つき MP4。
1. 羊皮紙の巻物が広がり、セピアのインクで描いた甲板平面図が現れる
（方位盤・題字・赤い封蝋つき、真上から）
2. 図面の線が光るワイヤーとして立ち上がる
3. 竜骨 → 肋材 → 外板（下から1段ずつ）→ 甲板 → 大砲 → マスト → 帆桁 → 索具 → 帆
→ 金の飾り・角灯・ドクロ旗 の順に組み上がる（カメラは船に寄る）
4. 紙が消え、下から海が満ちて船が浮かぶ。夕焼けの空と海が現れ、カメラは引いて全景へ
5. 角灯がともり、帆が風をはらんで進み出す（波に揺れ、航跡が白く伸びる）
6. 右舷の大砲が三発 → タイトル「海賊船」 → 最後に指定のロゴ
音は外部素材を使わず Python で合成する（6/8拍子の船乗りの歌、木槌・帆・波・かもめ・船鐘・大砲）。

【進め方】
- 図面のプレビュー画像を目で見て、文字の重なりを直す
- 本番の前にテスト静止画を数枚描いて確認する
- 本番レンダーは軽い設定で、PC を休ませながら回す。始める前に所要時間を伝えて了承を取る
